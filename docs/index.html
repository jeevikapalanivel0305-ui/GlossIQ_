What is GlossIQ?

GlossIQ is an AI-powered accelerator that automates the creation, enrichment, and management of business glossary terms across enterprise data catalogs. It bridges the gap between physical data assets and their business meaning.

ProductGlossIQ — Glossary Enricher Accelerator
Tech StackPython · Streamlit · Azure OpenAI · Microsoft Purview · Databricks Unity Catalog
Target UsersData Stewards, Governance Teams, CDOs, Business Analysts
DeploymentLocal / Streamlit Cloud / Azure App Service

How It Works

info

Keyword Detection Rules

ClassificationTrigger KeywordsConfidence
PII email, phone, mobile, address, dob, gender, name, contact 85–95%
Confidential salary, ssn, aadhaar, pan, passport, credit, bank, account 90–100%
Internal id, guid, uuid, key, reference, code 80%

When sample values are available, the engine applies regex patterns for higher-confidence detection:

Purview Integration Details

cloud
Authentication: OAuth2 client-credentials flow against Azure AD. Requires Service Principal with Data Catalog Reader role on the Purview account.
  • DNS + network validation before auth attempt
  • Account name format validation (3–63 chars, alphanumeric + hyphens)
  • Asset search via DataMap Atlas API with keyword + type + collection filters
  • Column schema discovery with GUIDs
  • Collection enumeration

Databricks Unity Integration Details

data_object
Authentication: Personal Access Token (PAT) with Unity Catalog permissions.
  • List catalogs, schemas, and tables
  • SQL warehouse discovery and execution
  • Column metadata retrieval via SQL statements
  • Tag push: key = column_name, value = business_term
  • Connection health validation

Security Architecture

  • Email-based authentication with password validation
  • Only pre-registered users (via RBAC Management) can login
  • Password reset requires current password verification
  • All Azure OpenAI calls stay within your Azure tenant boundary
  • No data leaves to external services — all processing is local or Azure-internal
  • Every approval/rejection decision is logged in the audit trail
  • Session-level queue isolation (pending items scoped per session)

Objection Handling

help_outline "We already have Purview"
GlossIQ enhances Purview — it adds AI-driven term generation, approval workflows, and conflict detection that Purview doesn't natively provide.
help_outline "How accurate is the AI?"
The Governance Engine provides a deterministic safety net. Sensitive data (PII, Confidential) is classified by rules with 100% confidence, not left to AI probability.
help_outline "What about data security?"
All processing uses Azure OpenAI within your tenant. No data leaves your Azure boundary. RBAC ensures only authorized users can approve terms.
help_outline "Can it scale?"
Multi-connector architecture, bulk operations, and semantic search with embeddings. The approval workflow handles hundreds of terms efficiently.

Troubleshooting

Common issues and their resolutions.

error_outline "DNS resolution failed for Purview"
check_circle Check account name spelling, VPN/firewall settings, and internet connectivity. Ensure DNS can resolve *.purview.azure.com.
error_outline "AADSTS700016 — Application not found"
check_circle Verify that the Client ID and Tenant ID belong to the same Azure AD tenant. The app registration must exist in the specified tenant.
error_outline "Databricks 401 — Authentication failed"
check_circle PAT has expired or lacks Unity Catalog permissions. Generate a new token with appropriate access.
error_outline AI returns empty suggestions
check_circle Check Azure OpenAI endpoint, API key, and deployment name in .streamlit/secrets.toml. Verify the deployment exists and is active.
error_outline Semantic search returns no results
check_circle Ensure the embedding deployment (text-embedding-ada-002) is configured in secrets. The glossary must have active (approved) terms.
error_outline Login fails for a user
check_circle Users must be added via RBAC Management by an Administrator. Only pre-registered users can authenticate.
